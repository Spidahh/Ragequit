# RAGEQUIT — Visual Strategy

La strategia visiva corrente e semplice: un solo sistema UI, una sola direzione grafica.

## Autorita

- CSS: `packages/client/public/game-ui.css`
- Performance: `02_TECH/06_visual_performance_contract.md`
- Asset esistenti: `02_TECH/10_deploy_status.md`

## Direzione

- Low-poly stylized action.
- Silhouette chiare.
- UI dark con accento gold.
- HP rosso `#FF3344`, Mana ciano `#00D0FF`, Stamina verde `#00FF88`.
- Fuoco `#FF4500`, Ice `#00E5FF`, Lightning `#FFE600`, Dark `#6A0DAD`,
  Nature `#39FF14`.

## Divieti

- Non ricreare layer CSS separati.
- Non aggiungere CSS di override per sistemare problemi locali.
- Non usare documenti di blueprint rimossi come fonte.
